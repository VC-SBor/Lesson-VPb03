# Lesson-VPb03 — Заметки

Небольшое консольное приложение для работы со списком заметок.

## Возможности

- добавить заметку (строку текста) в список;
- вывести все заметки на экран;
- удалить заметку по номеру;
- заметки сохраняются в `notes.json` и переживают перезапуск программы.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | точка входа: главный цикл и выбор действия по меню |
| `database.py` | слой данных: список заметок и чтение/запись `notes.json` |
| `utils.py` | слой логики: функции добавления, вывода, удаления и меню |
| `notes.py` | исходная версия «одним файлом» — оставлена для сравнения «до/после» |

## Запуск

```bash
python main.py
```

Python 3.10+, сторонние библиотеки не нужны.

## Как это устроено

Модули подключены через `import` и разделены по обязанностям:

- `utils.py` импортирует `database` и делегирует ему всю работу с данными;
- `main.py` импортирует функции из обоих модулей и содержит только цикл меню;
- `database.py` ни от кого не зависит — его можно переиспользовать в другом проекте.

Такое разделение упрощает масштабирование (новый модуль не трогает старые),
делает код нагляднее и помогает локализовать ошибки: проблема с данными —
ищем в `database.py`, проблема с вводом — в `utils.py`.
